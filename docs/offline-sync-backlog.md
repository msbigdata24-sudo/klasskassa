# Апельсин: backlog офлайн-синхронизации

Надежно сохранять траты без интернета и автоматически синхронизировать их при восстановлении сети без потери данных и дублей.

## Технические принципы
- Идемпотентность обязательна для всех офлайн-операций.
- Операции не удаляются из очереди при сетевой ошибке.
- Любая ошибка сервера должна быть видима пользователю (не "тихо пропадать").
- Локальная очередь очищается при logout.
