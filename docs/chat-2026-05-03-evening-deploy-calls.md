## Деплой на Render

- После удаления таблицы Prisma **`db push`** требовал **`--accept-data-loss`** — добавлен скрипт **`npm run build:render`** (`prisma db push --accept-data-loss && prisma generate && next build`), `render.yaml` переведён на него (`623d889`, ранее `a39a6cd`).
- В панели Render часто задана **своя** Build Command (не из yaml) — там нужно то же, что в README:  
  `npm install --include=dev && npm run build:render`
- **`npm audit fix --force` в билде** — опасно: npm предлагал откат **Next до 9.x**, сборка падала. Решение: **убрать** `audit fix --force` из цепочки; предупреждения audit не блокируют деплой.
- Поднят **`postcss` до `^8.5.10`**, в README предупреждение про audit (`7daa09a`).
- Итог: пользователь подтвердил, что **деплой починил** (команда без `audit fix --force`, актуальный `main`).
