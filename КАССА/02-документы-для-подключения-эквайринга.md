# Документы для подключения эквайринга (РФ)

Ниже базовый комплект, который обычно запрашивает провайдер (YooKassa/Т-Банк/CloudPayments). Точный список зависит от банка и юрформы.

## 1) По бизнесу

- [ ] ИНН
- [ ] ОГРН/ОГРНИП
- [ ] Выписка ЕГРЮЛ/ЕГРИП (актуальная)
- [ ] Паспорт директора/ИП
- [ ] Реквизиты расчетного счета
- [ ] Контакты ответственного (email, телефон)

## 2) По сайту/продукту

- [ ] Рабочий домен и доступный сайт
- [ ] Описание услуги и тарифов
- [ ] Публичная оферта
- [ ] Политика обработки персональных данных
- [ ] Политика возвратов
- [ ] Контакты поддержки
- [ ] Страница с реквизитами (если требуется провайдером)

## 3) По платежному сценарию

- [ ] Описание: "оплата в пользу третьего лица (gift)"
- [ ] Момент оказания услуги: "с момента активации Pro у получателя"
- [ ] Правило возврата: инициирует только плательщик
- [ ] Правило при возврате: доступ получателя может быть ограничен/отключен
- [ ] Ограничения и антифрод (лимиты, проверки)

## 4) По технике интеграции

- [ ] URL webhook (dev и prod)
- [ ] Секрет webhook
- [ ] Список статусов, которые обрабатываются в системе
- [ ] Идемпотентность запросов create payment
- [ ] Логирование платежного события и результата активации

## 5) Чеки (54-ФЗ)

- [ ] Выбран вариант фискализации (через провайдера/кассу)
- [ ] Определены предмет расчета/ставка НДС
- [ ] Проверено формирование чека "приход"
- [ ] Проверено формирование чека "возврат прихода"

## 6) Что не делать

- [ ] Не принимать оплату на личную карту как основной прод-сценарий для SaaS.
- [ ] Не запускать боевые списания до завершения тестового контура и документов.
