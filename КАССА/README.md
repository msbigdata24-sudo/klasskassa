# КАССА: единый набор для платежей

Сейчас проект работает в тестовом режиме: реальные списания не включаем, прием денег не запускаем.

Содержимое папки:

- `01-чеклист-тестовый-режим.md` - что сделать сейчас, до запуска реальных оплат.
- `02-документы-для-подключения-эквайринга.md` - что подготовить для подключения провайдера в РФ.
- `03-настройка-yookassa-test.md` - пошагово, как включить тестовый контур YooKassa.
- `04-сценарии-бета-тестов.md` - сценарии тестирования gift-flow с бета-тестерами.

Связанный документ по продуктовой/юридической логике gift-оплат:

- `docs/payments-ru-gift.md`
