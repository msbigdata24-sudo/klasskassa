# КлассКасса

Учёт родительских сборов в школьном классе: кто сдал взнос, кто нет, фото чека, публичный отчёт для WhatsApp. **Деньги через сервис не принимаются** — только статус оплаты.

Форк логики [Апельсина](../Апельсин) под школу (Next.js 15, Prisma, PostgreSQL).

## Запуск

```bash
copy .env.example .env
npm install
npx prisma db push
npm run dev
```

## Роли

- **Родительский комитет** (`COMMITTEE`) — создаёт сборы, отмечает оплату за любого, добавляет родителей и гостей.
- **Родитель** (`PARENT`) — отмечает свой взнос и прикрепляет чек.

## Основные маршруты

| Путь | Назначение |
|------|------------|
| `/classes` | Список классов |
| `/classes/[id]/collections/[collectionId]` | Сбор и статусы взносов |
| `/report/[code]` | Публичный отчёт без входа |
| `/invite/[code]` | Вступление в класс |
